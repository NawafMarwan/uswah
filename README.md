# موقع مركز أسوة للسيرة النبوية

موقع تعريفي من صفحتين في ملف واحد (`uswah.html`):

1. **التعريف**: محتوى الكتيب التعريفي كاملًا (التمهيد، لماذا السيرة اليوم، لماذا مركز أسوة، المنطلقات، الرؤية والرسالة، القيم، الأهداف الاستراتيجية) بهوية المركز وألوانه.
2. **الإحصائيات** (`#/stats`): لوحة **مشاهدات فقط** لمنصات X وتيليجرام ويوتيوب وتيك توك، مع:
   - اختيار المنصة، والفترة (آخر 7 / 30 / 90 يومًا، هذا الشهر، الشهر الماضي، هذه السنة، أو من تاريخ إلى تاريخ).
   - رقم إجمالي كبير، وبطاقة لكل منصة، ومخطط زمني لمشاهدات المنشورات، ومقارنة بين المنصات، وترتيب المنشورات الأعلى مشاهدة.
   - **وضع العرض** (ملء الشاشة للاجتماعات) و**طباعة / PDF**.
   - وضع ليلي ونهاري، وتصميم مخصص للجوال والحاسوب.

## طريقة الفتح

- **مباشرة**: افتح `uswah.html` في أي متصفح على الجوال أو الحاسوب. الصفحة تعمل وحدها لأن البيانات والصور مضمّنة فيها.
- **رابط ثابت (موصى به)**: فعّل GitHub Pages من إعدادات المستودع (Settings ← Pages ← Deploy from branch ← `main` / root). يصبح الرابط مثل `https://<اسم-الحساب>.github.io/uswah/`، ويفتح لوحة الإحصائيات مباشرة عبر `.../uswah.html#/stats`.

## من أين تأتي الأرقام؟

كل البيانات في `data/stats.json`، وتُنسخ تلقائيًا داخل `uswah.html`. نوعان من الأرقام:

| النوع | المعنى | مثال |
|---|---|---|
| `posts` | مشاهدات منشور واحد، ويُحسب ضمن الفترة حسب تاريخ نشره | منشورات تيليجرام |
| `periods` | إجمالي مشاهدات الحساب خلال فترة، كما تظهر في لوحة المنصة | تيك توك ويوتيوب من 27 أغسطس إلى 23 سبتمبر |

إذا اخترت فترة تتقاطع جزئيًا مع رقم «إجمالي فترة»، يُحسب بالتناسب مع عدد الأيام ويظهر بجانبه «≈ تقديري». والمنشورات التي يغطيها إجمالي فترة تظهر في القائمة دون أن تُضاف مرة ثانية.

الحساب يبدأ من **27 أغسطس 2026** لكل المنصات (الحقل `since` في `data/stats.json`)، ولا يُعدّ ما قبله.

أرقام تيك توك مدخلة يدويًا من TikTok Studio، وأرقام X يدوية كذلك. **المنصة التي لا بيانات لها لا تظهر للزوار.** المنصة التي ليس لها بيانات تُخفى تلقائيًا من الصفحة.

## الروابط

- `uswah.sa`: الصفحة الرئيسية (التعريف).
- `uswah.sa/stats`: لوحة الإحصائيات مباشرة. وهي أيضًا متاحة عبر `uswah.sa/#/stats`.

`index.html` و`stats/index.html` نسختان تُولَّدان تلقائيًا من `uswah.html` مع كل تحديث للبيانات، فلا تعدّلهما يدويًا.

## تصنيف منشورات تيليجرام

يُصنَّف كل منشور تلقائيًا عند الجلب، اعتمادًا على الوسوم المعتمدة والنص الكامل، ثم تُعرض الأرقام حسب النوع في لوحة الإحصائيات:

| النوع | القاعدة |
|---|---|
| الاقتباسات | الوسم `#اقتباسات_أسوة` |
| الكتب والمنظومات الصوتية | `#كتاب_صوتي` أو `#منظومات` أو عبارات مثل «كتاب صوتي» و«قصيدة» و«منظومة» |
| تصاميم الصلاة على النبي ﷺ | الوسم `#صلى_الله_عليه_وسلم` ومعه نص قصير جدًا |
| مقاطع الشمائل | ورود كلمة «الشمائل» (بعد استبعاد الإصدارات الصوتية) |
| إعلانات ومنشورات أخرى | ما عدا ذلك، ومنها المنشورات المصوّرة بلا نص |

لتصحيح تصنيف منشور بعينه، أضف في `data/stats.json` حقلًا على أعلى المستوى:

```json
"category_overrides": { "tg-4780": "shamail" }
```

والقيم المسموحة: `shamail` و`quotes` و`audio` و`salawat` و`other`. والرقم هو معرّف المنشور في تيليجرام بعد `tg-`.

## قسم «من إنتاجنا»

يعرض في الصفحة الرئيسية نماذج من أعلى التصاميم والمقاطع مشاهدةً، في ثلاثة تبويبات: الصلاة على النبي ﷺ، والاقتباسات، ومقاطع الشمائل.

- التصاميم تُنزَّل تلقائيًا من قناة تيليجرام مع الجلب اليومي، وتُحفظ في `assets/designs/` (أعلى 4 مشاهدةً لكل نوع، وتُحذف الأقدم تلقائيًا).
- مقاطع الشمائل تُعرض من يوتيوب (Shorts) بتشغيل مباشر داخل الصفحة، وتُكمَّل من تيليجرام بصورة مصغّرة ورابط للمنشور.
- القسم يختفي تلقائيًا إن لم توجد أي نماذج.

## بيانات X

لا يوجد حل مجاني تلقائي لـ X. تُدخل الأرقام يدويًا من لقطات شاشة التحليلات كما في تيك توك (انظر «إضافة أرقام يدويًا» أدناه). ويمكن لاحقًا ربط API الدفع حسب الاستخدام بإضافة السر `X_BEARER_TOKEN` فيعمل السكربت به تلقائيًا (غير مفعّل حاليًا).

## خطة النشر (`uswah.sa/plan`)

صفحة تعرض خطة المحتوى الشهرية من جدول Google Sheet. الجدول منشور كملف CSV، ورابطه في الحقل `plan_url` داخل `data/stats.json`، ويقرؤه الجلب اليومي فيحدّث الصفحة تلقائيًا. لا تغيّر ترتيب أعمدة الجدول: الأعمدة بعد «التاريخ» هي المشاريع، وكل صف يوم.

## تقارير الأثر الشهرية (PDF)

لكل شهر ملف PDF يضم إجمالي المشاهدات وكل منصة على حدة وعدد المنشورات حسب النوع (تصاميم الصلاة على النبي، الاقتباسات، مقاطع الشمائل، الكتب الصوتية، القصائد والمنظومات) وأعلى المنشورات مشاهدة. تظهر البطاقات في صفحة الإحصائيات.

- يبقى التقرير «غير متاح للتنزيل» حتى ينتهي الشهر **وتتوفر بيانات منصة X** لذلك الشهر (تُدخل يدويًا في `data/stats.json`).
- بعد ذلك يُولَّد الملف تلقائيًا مع التشغيل اليومي ويُحفظ في `reports/`، ويُعاد توليده إذا تغيّرت أرقام الشهر.
- المصدر: `scripts/make_report.py` (خط IBM Plex Sans Arabic المضمّن في `assets/fonts/`).

## ربط الحسابات (تحديث تلقائي يومي)

السكربت `scripts/fetch_stats.py` يجلب مشاهدات كل منشور، ويعمل يوميًا عبر GitHub Actions (`.github/workflows/update-stats.yml`)، ويمكن تشغيله يدويًا من تبويب Actions ← Update social views ← Run workflow.

أضف الإعدادات من: Settings ← Secrets and variables ← Actions. كل منصة مستقلة، والمنصة التي لا تُضاف إعداداتها تُتخطّى.

أسماء الحسابات (`YOUTUBE_CHANNEL` و`TELEGRAM_CHANNEL` و`X_USERNAME`) تكفي كتابتها في حقل `handle` داخل `accounts` في `data/stats.json`، ولا حاجة لإضافتها كمتغيرات إلا إذا أردت تجاوز تلك القيم.

| المنصة | ما تحتاجه | النوع في GitHub | ملاحظات |
|---|---|---|---|
| **يوتيوب** | `YOUTUBE_API_KEY` | Secret | مجاني. من Google Cloud Console فعّل «YouTube Data API v3» وأنشئ مفتاح API. |
|  | `YOUTUBE_CHANNEL` | Variable | معرّف القناة مثل `@uswah` أو `UC...` |
| **تيليجرام** | `TELEGRAM_CHANNEL` | Variable | اسم القناة العامة فقط (مثل `uswah`). لا يحتاج مفاتيح؛ يقرأ المشاهدات من صفحة القناة العامة `t.me/s/...`. الأرقام الكبيرة تأتي مقرّبة (مثل 1.7K). |
| **تيك توك** | `TIKTOK_CLIENT_KEY`, `TIKTOK_CLIENT_SECRET`, `TIKTOK_REFRESH_TOKEN` | Secrets | يتطلب تطبيقًا على developers.tiktok.com مع منتج «Login Kit» وصلاحية `video.list`، ثم تسجيل دخول حساب أسوة مرة واحدة للحصول على refresh token (صالح سنة). |
| **X** | `X_BEARER_TOKEN` | Secret | اختياري ومدفوع (غير مفعّل). الأرقام تُدخل يدويًا حاليًا. |


## إضافة أرقام يدويًا (تيك توك و X)

لا توجد في الموقع أي أدوات تعديل؛ الصفحة للعرض فقط. الأرقام تُدار من الملف `data/stats.json`:

- إجمالي حساب لفترة: أضف عنصرًا في `periods` (`platform` و`from` و`to` و`views`).
- منشور واحد: أضف عنصرًا في `posts` (`platform` و`id` و`date` و`title` و`views` و`url`).

ثم شغّل الأمر التالي لينسخ البيانات داخل `uswah.html`:

```bash
python3 scripts/fetch_stats.py --embed-only
```

## روابط الحسابات

عبّئ `accounts` في `data/stats.json` (`url` لكل منصة) لتظهر أيقونات الحسابات أسفل الموقع.
